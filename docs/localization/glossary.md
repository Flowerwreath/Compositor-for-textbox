# 영→한 용어집 (Photoshop 한국어판 기준)

Compositor를 한국어로 옮길 때의 기준이에요. 번역할 때 이 표를 먼저 봐요. 표에 없는 새 용어가 반복되면 여기에 추가해요.

비고 열의 표시:
- **PS**: Photoshop 한국어판에서 쓰는 번역
- **CR**: Camera Raw 한국어판에서 쓰는 번역
- **mac**: macOS 한국어 표준 메뉴의 번역
- **자체**: Photoshop에 같은 기능이 없어 새로 정한 번역
- **확인 필요**: 근거가 약해 사용자 확인이 필요한 것
- **G 확인**: Gemini(Antigravity) 리뷰에서 Photoshop·Camera Raw 한국어판과 맞는다고 판정한 것

## 원칙

- Photoshop 한국어판에 있는 용어는 그 번역을 따라요.
- 없는 용어는 Photoshop의 비슷한 기능에 맞춰 짓고 "자체"로 표시해요.
- 번역하지 않는 것:
  - 약어와 단위: RGB, HSL, px, %, DPI, EV, K, in, cm, mm
  - 앱 이름과 제품 이름: Compositor, Camera Raw, Photoshop, iPhone, MacBook Pro, Studio Display, Instagram, YouTube
  - 키보드 키 이름: Delete, Return, Esc, Tab, Space
  - 키 기호: ⌘⇧⌥⌃
- 메뉴 항목 끝의 "…"는 그대로 둬요.
- 버튼과 메뉴는 Photoshop 한국어판처럼 짧은 명사구로 써요(예: "레이어 복제", "선택 해제"). "~하기"는 Photoshop이 그렇게 쓰는 곳(예: "가로로 뒤집기")에만 써요.
- 툴팁과 안내 문장은 해요체가 아니라 짧은 평서형 명사문이나 "~해요"를 쓰지 않는 설명체로 써요. 예: "드래그하여 칠하기 · [ ] 크기", "이 레이어는 숨겨져 있습니다. 표시하면 칠할 수 있습니다." macOS 한국어 앱의 오류·안내 문장처럼 "~습니다"체를 써요(사용자 결정).
- "Option", "Shift", "Command(Cmd)", "Control" 같은 수정 키 이름은 macOS 한국어판처럼 그대로 써요(예: "Option-클릭").
- 대·소문자만 다른 영어 키("Zoom In"/"Zoom in")는 같은 한국어로 옮겨요.
